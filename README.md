Pre správne stiahnutie programu si môžete rovno nainštalovať súbor project.zip,
ktorý by mal po rozbalení obsahovať projekt v správnej štruktúre (pozri Používateľskú príručku, časť 3., Štruktúra projektu).
Na oboznámenie sa s projektom odporúčam prečítať si Používateľskú príručku. 
Kryptografická príručka slúži na uvedenie do deja kryptografie pre tých, ktorí s ňou majú malé alebo vôbec žiadne skúsenosti,
pre pokročilých bude možno slúžiť ako osvieženie základov.

Prajem veľa zdaru a zábavy pri využívaní tohto projektu!
